## Uso recomendado en ChatGPT

- Para conversar y continuar una escena, inicia un chat nuevo y selecciona **Chat** si aparece el selector **Chat/Work**. Este núcleo no necesita abrirse como una tarea Work.
- Carga primero solo este archivo y la carpeta o paquete **CHAT_BASE**. No pidas que lea simultáneamente toda `00_FUENTES/historia_original`.
- La historia original se conserva aparte como matriz de consulta. Ábrela o adjúntala únicamente cuando una pregunta histórica requiera localizar una escena, reacción o frase concreta.
- En la exportación **CHAT_BASE** de Drive, `INVENTARIO_FUENTES.md` describe la matriz pero no contiene sus 13 archivos originales. Si esos archivos no están adjuntos, no afirmar que se verificó una escena ni reconstruir una microinteracción de memoria: solicitar el tramo histórico pertinente o marcar la respuesta como `FUENTE_NO_ADJUNTA`.
- Si el chat se vuelve lento, no es una señal para reescribir el canon: reinicia un chat y vuelve a cargar únicamente este mapa y el bloque que corresponda (personajes, cultura, economía o mundo).
- Work queda reservado para auditorías largas, exportaciones o reorganizaciones de archivos; no es el modo recomendado para una conversación normal de la historia.

Orden de precedencia:

1. Correcciones directas del usuario.
2. Escenas y correcciones contenidas en `00_FUENTES/historia_original/`.
3. `05_CONTINUIDAD/CURRENT_STATE_5_FLORIS_AÑO3.md` para el punto actual; `CURRENT_STATE_4_FLORIS_AÑO3.md` queda como corte histórico conservado.
4. Canon, fichas, sistemas, finanzas y deltas derivados.
5. Semillas de vida autónoma, que son posibilidades preparadas y no hechos consumados hasta que una escena las confirme.

Cuando una fuente contiene una versión inicial y una corrección posterior, conservar ambas como historial, pero obedecer la corrección posterior. Nunca borrar ni sobrescribir la fuente original.
